### 2️⃣ 管理员功能测试

- 确认删除

#### 删除评论
- 在评论列表中，每条评论旁边有红色的 × 按钮（仅管理员可见）
- 点击 × 按钮
- ✓ 该评论应该被删除

### 3️⃣ 点赞功能测试

#### 爱心样式
- 查看帖子卡片下方的点赞按钮
- ✓ 未点赞时: 黑色边框，透明中间，白色背景
- ✓ 点赞时: 红色边框，红色填充，浅红色背景

#### 点赞动画
- 点击任意帖子的爱心按钮
- ✓ 爱心应该有跳动效果（放大缩小）

#### 单次点赞限制
- 用同一个账号点赞同一个帖子
- ✓ 第一次点赞，点赞数 +1，爱心变红
- ✓ 第二次点击，取消点赞，点赞数 -1，爱心恢复黑色

#### 游客无法点赞
- 点击"Guest Access"进入游客模式
- 尝试点赞
- ✓ 点赞按钮应该是禁用状态（灰色）
- ✓ 点击后应提示"游客不能点赞，请先登录"

## 📊 数据验证

### localStorage 检查
在浏览器开发者工具中检查：
1. **blog_users**: 已注册的用户列表
2. **blog_session**: 当前登录会话
3. **blog_posts**: 博客文章数据
4. **user_profile**: 用户自定义信息（用户名等）

### 点赞数据结构
```javascript
// 查看帖子的 likes 字段应该是对象格式：
{
  "username1": true,
  "username2": true
}

// 而不是数字格式：
// 12 (旧格式，应该已自动迁移)
```

## 🐛 常见问题排查

### Q: 已注册的账号无法登录
- [ ] 检查账号是否输入正确（注意大小写）
- [ ] 检查密码是否正确
- [ ] 尝试清除浏览器缓存和 localStorage
- [ ] 检查浏览器开发者工具的 Console 是否有错误日志

### Q: 点赞后没有变红色
- [ ] 检查浏览器是否支持 SVG
- [ ] 检查 CSS 是否正确加载
- [ ] 刷新页面重试

### Q: 用户名修改后没有实时显示
- [ ] 检查是否点击了"Save"按钮
- [ ] 新评论应该会显示新用户名，旧评论保持原名称

### Q: 浏览器返回键仍然有效
- [ ] 这个功能可能被某些浏览器插件阻止
- [ ] 尝试在隐私模式下测试
- [ ] 使用现代浏览器（Chrome、Firefox、Safari 等）
